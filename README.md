# 🌦️ Weather Web App

A simple and responsive weather application that displays real-time weather information for any city worldwide. Built with **HTML, CSS, and JavaScript**, this project uses a public weather API to fetch live weather data and display it in a clean and user-friendly interface.

## ✨ Features

- 🌍 Search weather by city name  
- 🌡️ Real-time temperature, humidity, and weather condition  
- 📍 Auto-detect user’s location (optional)  
- ☁️ Weather icons and dynamic background  
- 📱 Fully responsive UI for mobile and desktop

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the web app  
- **CSS3** – Styling and responsive design  
- **JavaScript (ES6)** – Fetching weather data and DOM manipulation  
- **OpenWeather API** – Real-time weather data provider
